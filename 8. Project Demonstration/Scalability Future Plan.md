## 1. Database Scaling (Migrating to Cloud SQL)

For a large-scale commercial launch, the local SQLite database will be replaced with Google Cloud SQL (PostgreSQL), utilizing connection pools and replica read nodes to handle concurrent users.

## 2. Voice Integration (Text-to-Speech)

Implement speech synthesis on generated warm openers. This will allow professionals to review their talking points on headphones while walking into conference rooms.

## 3. Automated Calendar & LinkedIn Syncing

Integrate Google Calendar and LinkedIn API. The assistant will automatically scan upcoming calendar invites and pre-generate strategic networking dossiers, eliminating manual event inputs.
