## 1. Feature 1: User Registration, Login & Detailed Profiles

Allows users to create accounts, secure them via bcryptjs hashes, and manage custom profiles (Profession, Role, Career Goals, Interests).

## 2. Feature 2: Customizable Pricing Tiers

Includes Basic, Executive, and Enterprise tiers. Prompts the user to enter custom contribution values when selecting premium tiers.

## 3. Feature 3: Live Wikipedia Fact-Checker

Queries Wikipedia APIs to verify event niches or company backgrounds, providing live background info directly on the client UI.

## 4. Feature 4: 22-Category AI Starter Generator

Queries Gemini models server-side, generating conversation scripts grouped by scenario (Lobbies, Speaker transitions, follow-up emails, pitches, elevator lines).

## 5. Feature 5: Connection History & Persistent Logs

Preserves previous generations in SQLite, providing searching, sorting, and row deletion capabilities.

## 6. Feature 6: Rating Loops & Interactive SaaS Analytics
